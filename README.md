<h1 align="center"> Automated Cross-Tabulation & Reporting Pipeline for Survey Data</h1>

<p align="center">
A Python-based automation workflow for generating custom survey tables directly from SPSS (<code>.sav</code>) files into clean, formatted Excel reports.
</p>

<p>
This project was built to reduce the repetitive manual work involved in creating survey cross-tabulations, frequency tables, and demographic breakdowns.
</p>

<hr>

<h2> Project Overview</h2>

<p>Working with survey data often involves:</p>

<ul>
<li>Repetitive table generation</li>
<li>Manual recoding</li>
<li>Copying outputs into Excel</li>
<li>Formatting tables repeatedly</li>
</ul>

<p>This pipeline automates the entire process.</p>

<p>Using Python, the script:</p>

<ul>
<li>Reads SPSS survey datasets</li>
<li>Processes selected variables</li>
<li>Generates count and percentage tables</li>
<li>Handles multi-response questions</li>
<li>Supports variable recoding and category merging</li>
<li>Applies automatic Excel formatting</li>
<li>Stacks tables into a single report sheet</li>
</ul>

<p>
The goal is to make survey reporting faster, cleaner, and reproducible.
</p>
